COURSE STRUCTURE OVERVIEW:
-----------------------------------------------------------------------------
1. PHASE 1: CONCEPTUAL FOUNDATION (Modules 01 - 10)
   - Modules 01 to 06: Core Python concepts (Functions, Modules, OOP, JSON, 
     Decorators, Exceptions) with isolated concept scripts in Module_Code/.
   - Modules 07 to 09: Web and HTTP theory (Client-Server, Methods, Status Codes) 
     covered in Preparation_guide/ text files (no coding required).
   - Module 10: Introduction to Flask ("Hello World" concept).

2. PHASE 2: HANDS-ON PROJECT IMPLEMENTATION (Modules 11 - 26)
   - The Task Manager Application (TaskFlow) officially starts at MODULE 11!
   - Every module from 11 to 26 adds specific code and features to the project.

MODULE 16: Database Fundamentals
-----------------------------------------------------------------------------
* Teaching Day    : Day 4
* Project Step    : Step 6
* Files Affected  : 
    1. database.py
* Functionality Added:
    - Explain that in-memory lists vanish when the server restarts.
    - Design the relational database schema:
      - 'users' table: id (PRIMARY KEY), username, email, created_at
      - 'tasks' table: id (PRIMARY KEY), user_id (FOREIGN KEY), title, description, status
* Schema in database.py:
    CREATE TABLE users (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        username TEXT NOT NULL UNIQUE,
        email TEXT NOT NULL UNIQUE
    );
    CREATE TABLE tasks (
        id INTEGER PRIMARY KEY AUTOINCREMENT,
        user_id INTEGER,
        title TEXT NOT NULL,
        status TEXT DEFAULT 'Pending',
        FOREIGN KEY (user_id) REFERENCES users(id)
    );
* Instructor Tip:
    Explain why Foreign Keys matter: each task belongs to a specific user.

MODULE 17: SQL Basics
-----------------------------------------------------------------------------
* Teaching Day    : Day 4
* Project Step    : Step 7
* Files Affected  : 
    1. database.py
* Functionality Added:
    - Implement SQL CRUD operations using Python's sqlite3 library:
      - CREATE: INSERT INTO tasks (title, description, status) VALUES (?, ?, ?)
      - READ  : SELECT * FROM tasks WHERE status = ? ORDER BY id DESC
      - UPDATE: UPDATE tasks SET title = ?, status = ? WHERE id = ?
      - DELETE: DELETE FROM tasks WHERE id = ?
    - Use '?' parameter placeholders to protect against SQL Injection.
* Instructor Tip:
    Demonstrate that entering "' OR 1=1 --" into a raw SQL query is dangerous, 
    and show how '?' placeholders keep the application 100% safe.
