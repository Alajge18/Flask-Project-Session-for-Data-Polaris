About TaskFlow

A Flask-based Task Management System built during the Data Polaris Workshop.

What is TaskFlow?

TaskFlow is a personal task management system that lets you create, view, update, and delete tasks. It was built step-by-step across a 6-day workshop covering Python, Flask, SQLite, and deployment.

Technology Stack

  • Python — Programming Language
  • Flask — Web Framework
  • SQLite — Database
  • Flask-WTF — Form Validation
  • Jinja2 — Template Engine
  • HTML/CSS — Frontend

Features

  • ✓ Create, Read, Update, Delete tasks
  • ✓ Filter tasks by status
  • ✓ Search tasks by title/description
  • ✓ REST API with JSON responses
  • ✓ Form validation with Flask-WTF
  • ✓ Dashboard with task statistics
  • ✓ SQLite database for persistence
